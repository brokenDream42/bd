## 🔧 Процедура 1: TOP_DOGS1

### Назначение
Определение N самых высокооплачиваемых сотрудников

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| p_n | NUMBER | Количество сотрудников для выборки |

### Особенности
- Использует курсор с сортировкой по зарплате (DESC)
- Обрабатывает случай n=0 (ошибка)
- Обрабатывает случай n > COUNT(*) (предупреждение)
- Автоматически очищает таблицу TOP_DOGS перед выполнением

### Пример использования

```sql
EXEC TOP_DOGS1(5);
SELECT * FROM TOP_DOGS;
