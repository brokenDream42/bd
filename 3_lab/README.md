
# Лабораторная работа 3: Работа с процедурами в Oracle

## 📋 Описание

Лабораторная работа посвящена созданию и использованию **PL/SQL процедур** для обработки данных о сотрудниках, отделах и заказах. В работе реализованы различные типы процедур, демонстрирующие ключевые концепции программирования в Oracle:

- **Работа с курсорами** (явные и неявные)
- **Обработка ошибок и исключений** (EXCEPTION, WHEN OTHERS)
- **Динамическое выполнение SQL** (EXECUTE IMMEDIATE)
- **Аналитические функции** и подзапросы
- **Функции агрегации и группировки** (COUNT, LISTAGG, ROW_NUMBER)
- **Условная обработка и циклы**
- **Модификация данных** (INSERT, UPDATE, DELETE)

| Таблица | Описание |

## 🔧 Реализованные процедуры

### 1️⃣ Процедура: TOP_DOGS1

#### Назначение
Определение **N самых высокооплачиваемых сотрудников** с использованием явного курсора.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| p_n | NUMBER | Количество сотрудников для выборки |

#### Ключевые особенности
- ✅ Использует **явный курсор** с сортировкой по зарплате (DESC)
- ✅ **Валидация входных параметров**: 
  - Если `p_n = 0` → выводит ошибку и завершает работу
  - Если `p_n > COUNT(*)` → выводит предупреждение, но продолжает работу
- ✅ **TRUNCATE TABLE** автоматически очищает таблицу TOP_DOGS перед вставкой
- ✅ **Транзакция с COMMIT** для фиксации изменений
- ✅ **Обработка исключений** (EXCEPTION WHEN OTHERS)

#### SQL запрос, используемый в курсоре
```sql
SELECT last_name, salary
FROM s_emp
ORDER BY salary DESC
```

#### Пример использования

```sql
-- Получить 5 самых высокооплачиваемых сотрудников
EXEC TOP_DOGS1(5);
SELECT * FROM TOP_DOGS;

-- Результат:
-- last_name    | salary
-- -------------|----------
-- Соколов    | 150000
-- Петров     | 145000
-- и т.д.
```

#### Результаты после выполнения
Таблица TOP_DOGS содержит:
- `last_name` - фамилию сотрудника
- `salary` - размер зарплаты

### 2️⃣ Процедура: SHOW_EXPERIENCED_EMPLOYEES

#### Назначение
Вывод списка **опытных сотрудников** (со стажем более N лет) с информацией о регионе и количестве обработанных заказов.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| p_years | NUMBER | Минимальный стаж в годах |

#### Ключевые особенности
- ✅ **Курсор с параметром**: использует параметризованный курсор для гибкости
- ✅ **JOIN операции**: объединяет данные из 4 таблиц (S_EMP, S_DEPT, S_REGION, S_ORD)
- ✅ **LEFT JOIN** для S_ORD (сотрудник может не иметь заказов)
- ✅ **MONTHS_BETWEEN** для вычисления стажа в месяцах
- ✅ **GROUP BY** для подсчета количества заказов
- ✅ **DBMS_OUTPUT** для форматированного вывода в консоль

#### SQL запрос, используемый в курсоре
```sql
SELECT e.last_name, 
       r.name AS region_name, 
       COUNT(o.id) AS order_count
FROM s_emp e
JOIN s_dept d ON e.dept_id = d.id
JOIN s_region r ON d.region_id = r.id
LEFT JOIN s_ord o ON e.id = o.sales_rep_id
WHERE MONTHS_BETWEEN(SYSDATE, e.start_date) > p_min_months
GROUP BY e.last_name, r.name
```

#### Пример использования

```sql
-- Вывести опытных сотрудников со стажем более 2 лет
EXEC SHOW_EXPERIENCED_EMPLOYEES(2);

-- Результат вывода в консоль:
-- Сотрудники со стажем более 2 лет:
-- Сотрудник: Иванов, Регион: Европа, Заказов: 12
-- Сотрудник: Сидоров, Регион: Азия, Заказов: 8
```

### 3️⃣ Процедура: ADD_STARS

#### Назначение
Добавление **визуального отображения процента комиссии** в виде звездочек в новый столбец `STARS`.

#### Ключевые особенности
- ✅ **ALTER TABLE** для добавления столбца STARS (VARCHAR2) к таблице S_EMP
- ✅ **FOR UPDATE** - курсор с возможностью обновления текущей записи
- ✅ **Динамическое формирование строки** звездочек на основе процента комиссии
- ✅ **NVL()** для обработки NULL значений комиссии
- ✅ **ROUND()** для округления процента до целого числа
- ✅ **WHILE цикл** для создания строки звездочек
- ✅ **UPDATE WHERE CURRENT OF** для обновления текущей записи в курсоре

#### Алгоритм
1. Получить процент комиссии и округлить его
2. Создать строку из звездочек количеством, равным проценту
3. Обновить столбец STARS для каждого сотрудника
4. Зафиксировать изменения через COMMIT

#### Пример использования

```sql
-- Выполнить процедуру и добавить звездочки
EXEC ADD_STARS;

-- Просмотреть результаты
SELECT last_name, commission_pct, stars FROM s_emp;

-- Результат:
-- last_name     | commission_pct | stars
-- -------------|----------------|----------
-- Иванов       | 10             | **********
-- Петров       | 5              | *****
-- Сидоров      | NULL           | 
```

### 4️⃣ Процедура: SHOW_MANAGERS_SUBORDINATES

#### Назначение
Вывод списка **менеджеров и их подчиненных** со стажем более N лет.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| p_years | NUMBER | Минимальный стаж подчиненных в годах |

#### Ключевые особенности
- ✅ **Self-join** таблицы S_EMP (сотрудники объединяются с менеджерами)
- ✅ **LISTAGG()** для объединения списка подчиненных в одну строку
- ✅ **GROUP BY manager_id** для группировки подчиненных по менеджеру
- ✅ **ORDER BY within GROUP** для сортировки подчиненных по фамилии
- ✅ **MONTHS_BETWEEN()** для фильтрации по стажу
- ✅ **NVL()** для обработки случаев отсутствия подчиненных

#### SQL запрос в процедуре
```sql
SELECT 
    m.last_name AS manager_name,
    LISTAGG(e.last_name, ', ') WITHIN GROUP (ORDER BY e.last_name) AS subordinates
FROM s_emp e
JOIN s_emp m ON e.manager_id = m.id
WHERE MONTHS_BETWEEN(SYSDATE, e.start_date) > (p_years * 12)
GROUP BY m.last_name
```

#### Пример использования

```sql
-- Вывести менеджеров со своими подчиненными (стаж > 1 года)
EXEC SHOW_MANAGERS_SUBORDINATES(1);

-- Результат вывода:
-- Менеджеры и подчиненные (> 1 лет):
-- Менеджер: Федоров | Подчиненные: Иванов, Петров, Сидоров
-- Менеджер: Волков | Подчиненные: Смирнов
```

### 5️⃣ Процедура: TOP_DOGS2

#### Назначение
**Улучшенная версия TOP_DOGS1** - поиск N самых высокооплачиваемых сотрудников с использованием **аналитического подхода** вместо курсора.

#### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| p_n | NUMBER | Количество сотрудников для выборки |

#### Ключевые особенности
- ✅ **Вложенный запрос с ROWNUM** для определения N-й зарплаты
- ✅ **DISTINCT** для получения уникальных значений зарплат
- ✅ **ORDER BY salary DESC** с ROWNUM для ранжирования
- ✅ **Условие salary >= v_nth_salary** для получения всех сотрудников с этой зарплатой и выше
- ✅ **Лучшая обработка случаев**: когда несколько сотрудников имеют одинаковую зарплату
- ✅ **Подзапрос LISTAGG** в SELECT для получения списка сотрудников с одинаковой зарплатой
- ✅ **SQL%ROWCOUNT** для получения количества вставленных строк
- ✅ **NO_DATA_FOUND исключение** обработка

#### Отличия от TOP_DOGS1

| Аспект | TOP_DOGS1 | TOP_DOGS2 |
|--------|-----------|----------|
| **Подход** | Курсор + цикл | SQL запрос + аналитика |
| **Добавление столбца** | 2 столбца (last_name, salary) | 3 столбца (+ comments) |
| **Обработка одинаковых зарплат** | Первые N сотрудников | Все сотрудники с N-й зарплатой+ выше |
| **Comments** | Нет | Список других сотрудников с такой же зарплатой |
| **Валидация** | Предупреждение при n > COUNT | Ошибка при n > COUNT |

#### Пример использования

```sql
-- Получить 6-х самых высокооплачиваемых сотрудников
EXEC TOP_DOGS2(6);
SELECT * FROM TOP_DOGS;

-- Результат:
-- last_name    | salary | comments
-- -------------|--------|----------------------------------
-- Соколов    | 150000 | 
-- Петров     | 145000 | Смирнов, Федоров
-- и т.д.
```

**Примечание**: Если несколько сотрудников имеют одинаковую зарплату, они все будут добавлены в результат, даже если это приведет к количеству > N.

## 📝 Очистка и переинициализация

Скрипт `main.sql` начинается с **автоматической очистки** всех созданных ранее объектов:

```sql
DROP TABLE TOP_DOGS;
DROP PROCEDURE TOP_DOGS1;
DROP PROCEDURE TOP_DOGS2;
DROP PROCEDURE SHOW_EXPERIENCED_EMPLOYEES;
DROP PROCEDURE SHOW_MANAGERS_SUBORDINATES;
```

Это гарантирует, что:
- ✅ Скрипт можно запускать несколько раз без ошибок
- ✅ Все старые данные и объекты будут пересозданы
- ✅ Нет конфликтов с существующими процедурами

## 🎯 Ключевые концепции PL/SQL

### 1. Курсоры
- **Явные курсоры**: TOP_DOGS1, SHOW_EXPERIENCED_EMPLOYEES, ADD_STARS
- **Неявные курсоры**: используются в SELECT INTO statements
- **Параметризованные курсоры**: SHOW_EXPERIENCED_EMPLOYEES для гибкости

### 2. Обработка исключений
```sql
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        -- обработка отсутствия данных
    WHEN OTHERS THEN
        -- обработка всех остальных ошибок
```

### 3. Динамический SQL
```sql
EXECUTE IMMEDIATE 'DROP TABLE TOP_DOGS';  -- выполнение SQL строки в runtime
```

### 4. Аналитические функции
- `ROWNUM` - номер строки в результате
- `LISTAGG()` - агрегирование строк в одну строку
- `MONTHS_BETWEEN()` - вычисление разницы в месяцах

### 5. Модификация структуры
```sql
ALTER TABLE s_emp ADD stars VARCHAR2(100);  -- добавление столбца
```
